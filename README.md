# filterwise-site

Public pages for the Filterwise Chrome extension, served by GitHub Pages:

- Privacy policy: https://leekycauldron.github.io/filterwise-site/privacy.html
- Support: https://leekycauldron.github.io/filterwise-site/support.html

This repository contains only these pages. The extension's source lives in a separate private
repository, where `site/` is the source of truth for this content.
